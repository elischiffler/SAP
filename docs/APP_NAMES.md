# App names for speech

92 exact bundle-ID mappings, verified November 14, 2026. Lookup is local and adds no API calls or network dependency to notification processing. The original request payload and grouping key stay unchanged. Known IDs are matched without casing differences; unknown apps retain their supplied name. Already-generated WAVs are not rewritten.

Native IDs use [Apple’s deployment reference](https://support.apple.com/en-nz/guide/deployment/depece748c41/web). Third-party IDs were retrieved from Apple’s `https://itunes.apple.com/lookup?id=<App Store ID>&country=us` API. Short spoken labels omit App Store marketing subtitles.
